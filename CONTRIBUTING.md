# Contributing to PREMIUM+ Community Edition

Thanks for wanting to help independent contractors get practical, accessible software.

## Current stage

This repository currently contains project documentation and screenshots from the separate PREMIUM+ Commercial staging application. **The installable Community Edition application source has not been publicly released.** Please do not present the screenshots as proof of a ready-to-install product.

## Ways to contribute now

- Open an Issue describing a real contractor workflow problem: estimates, proposals, PDF import, photos, job tracking, homeowner approvals, or warranty visits.
- Suggest a clear, accessible mobile workflow that works well on an iPhone and desktop.
- Review documentation or propose test cases, particularly cross-company data privacy, PDF reliability, uploads, and backups.
- Help test the code once an audited Community Edition source release becomes available.

## Contribution guidelines

1. Check existing Issues before opening a duplicate.
2. For bugs, explain what happened, what you expected, and steps to reproduce using **fictional** projects.
3. Do not post real property/customer records, credentials, personal addresses, payments, or private photos to Issues or Pull Requests.
4. Keep proposed changes small and focused; include tests where applicable.
5. Respect the existing AGPLv3 licensing and the licenses of third-party packages and assets.
6. Never introduce a required paid service or send jobsite photographs to an outside provider without a clear opt-in and alternative.
7. Do not claim a feature is finished until it has passed the relevant tests.
