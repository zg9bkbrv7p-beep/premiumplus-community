# Current boundaries

The community package contains source implementations for project management, estimates/proposals, accepted contracts, homeowner permissions, photo uploads, local finish-color studies, PDF import and simple 2D/3D design.

Not included: hosted SaaS account, guaranteed architectural dimensions, professional permit drawings, legally qualified engineering advice, fully automated photo-to-3D reconstruction, built-in photorealistic remodeling without a third-party provider, or a promise of always-available AI.

A color-tinted image is described as a **color study**, not a generated photorealistic architectural edit. All estimates and measurements need verification by the contractor.
