# Getting Codex working with PREMIUM+ Community Edition

**Repository:** [zg9bkbrv7p-beep/premiumplus-community](https://github.com/zg9bkbrv7p-beep/premiumplus-community)

This is the public Community Edition source. It is **not** a mirror or backup of the currently running Commercial staging service.

## On the Codex mobile composer

1. Open the repository/environment selector (the name above **Ask Codex**).
2. Pick a Codex Cloud environment containing `zg9bkbrv7p-beep/premiumplus-community`.
3. If it does not appear, open Codex on the web or desktop to connect the GitHub repository and prepare/publish a cloud environment, then return to mobile.
4. Select `6 Astra` if available, and choose a higher intelligence setting when a difficult repo-wide audit needs it.
5. Begin with a **read-only audit** and ask for a report. No deployment or remote database changes.

## First task to paste in Codex

> Inspect the **current public PREMIUM+ Community Edition repository** and its AGENTS.md instructions. Audit authentication, company isolation, proposals/PDF import, photo uploads, homeowner approvals, Live Project, tests, and release safety. Do not modify code, deploy, contact outside services, or access the separate private Commercial application. Report verified findings with file paths, a prioritized fix plan, and tests to run. Treat the repository as a pre-release candidate.

## After the first report

Review its findings before approving individual fixes. When a specific fix is authorized, have Codex create a feature branch and pull request for review. Run the documented automated checks.

**Do not select** `los-tres-amigos-coordination`, `premiumplus-vision-staging`, or `premiumplus-v11-cloudflare` when the requested work is on the public Community Edition. These are different projects.

The source is open under AGPLv3, but other third-party projects and assets can have separate rights. Check licenses before adapting outside code.
